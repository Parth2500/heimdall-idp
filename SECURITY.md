# Security policy

Heimdall is a portfolio project in early development. It has not had an independent security review. Do not use it in production.

## Report a vulnerability

Use the private reporting feature of GitHub: open the **Security** tab of this repository and select **Report a vulnerability**. Do not open a public issue for a vulnerability.

Include the affected endpoint or file, the steps to reproduce, and the effect you expect.

## Design documents

The security decisions are in [docs/threat-model.md](docs/threat-model.md). If a report shows a gap in that model, the fix includes an update to the model.
