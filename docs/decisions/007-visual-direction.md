# DR-007: Visual direction of the account pages: U13, then U15, then U16

- Date: 2026-10-19 to 2026-10-25
- Status: U16 accepted. U13 and U15 superseded.
- Affects: U13, U15, and U16 in the front-end design.

## Before

2026-10-19: Claude chose U13, a public-service look, when the owner delegated the visual design. 2026-10-23: the owner replaced it with U15, Burning Bridge, which the owner drew in Figma.

## After

2026-10-25: the owner replaced U15 with U16, the Ledger card: one centered card, IBM Plex fonts from Heimdall's own origin, night and day themes.

## Reason

The owner chose U16 because the design is more mature. Each direction keeps one security rule: every page shows the tenant host, so the user can compare it with the address bar.

## Consequences

The demo SPA keeps the U13 look, so a user sees that it is a different site. The email-first sign-in of the U16 mockups waits for the account picker (#41).
